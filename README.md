# 찬양의 방 — 온라인 찬양반 연습실

여의도순복음교회 중등2부 에셀찬양대 Phase 1 정적 웹 프로토타입. Three.js r170 ES modules와 CSS3DRenderer를 CDN에서 불러옵니다. 빌드·로그인·서버 데이터베이스가 필요 없습니다.

## 실행

이 폴더에서 다음을 실행하고 <http://localhost:8000>에 접속하세요.

```sh
python3 -m http.server 8000
```

`file://`로 HTML을 직접 열면 모듈과 JSON을 읽지 못합니다. 인터넷 연결이 필요합니다(Three.js CDN, Google Fonts, YouTube). 폰에서는 같은 Wi-Fi에서 컴퓨터의 LAN IP와 포트로 접속합니다. 소리는 사용자가 재생 버튼을 누른 뒤 시작됩니다.

## 사용

- 닉네임과 파트를 선택해 입장합니다. 닉네임을 비우면 성경 이름을 무작위로 부여합니다.
- 바닥 클릭: 이동 / 드래그: 카메라 회전 / 휠: 확대·축소. W A S D와 방향키는 보조 이동입니다.
- 모바일: 좌하단 터치 조이스틱 이동, 3D 화면 드래그로 시점 회전. 화면 회전을 지원합니다.
- 의자 가까이에서 E 또는 앉기 버튼으로 앉기·일어서기.
- 하단 이모트 네 개: 3초 동안 표시되는 몸짓. 악보대 클릭 또는 ‘오늘의 찬양’으로 곡 목록을 엽니다.
- 스크린 앞쪽으로 다가가 ‘스크린 보기’를 누르면 YouTube 확대 창과 재생·일시정지·다음 영상·음량 컨트롤을 이용할 수 있습니다. 닫으면 같은 플레이어가 벽으로 돌아갑니다.
- 곡의 ‘연습’을 누르면 메트로놈 BPM이 바뀝니다. 소리 켜기·끄기는 별도입니다. 30–240 BPM, 첫 박 강조. 다른 탭으로 전환하면 메트로놈을 정지합니다.
- 화면의 인원은 본인뿐입니다. 영상·메트로놈은 로컬 재생이며 동기화하지 않습니다.

## 영상 목록 교체

`playlist.json`의 `videos`를 수정한 후 페이지를 새로고침하세요. 기존 3개 영상은 교회 예배 녹화 임시 목록입니다. 시작·종료 값 0–900은 **찬양 구간을 검증한 타임스탬프가 아닙니다**. 실제 찬양 구간으로 교체하세요.

```json
{
  "note": "운영자용 설명",
  "videos": [
    { "id": "knblj0zKX_k", "title": "예배 찬양", "start": 0, "end": 900 }
  ]
}
```

- `id`: YouTube URL의 `v=` 뒤 11자리 ID 또는 `youtu.be/` 뒤 ID. 전체 URL을 넣지 않습니다.
- `title`: 목록에 표시할 영상명.
- `start` / `end`: 초 단위, 선택값. `end`는 `start`보다 커야 합니다. 영상 파일을 다운로드하거나 잘라 저장하지 않고 IFrame Player API의 구간 재생을 사용합니다.
- 공개 또는 일부 공개이며 임베드가 허용된 영상을 사용하세요. 연령·지역 제한, 소유자의 외부 재생 제한 및 네트워크 정책으로 재생이 실패할 수 있습니다. 확대 창에 오류 안내를 표시합니다.
- 다음 영상은 버튼으로 선택합니다. 영상 종료 시 자동으로 다음 곡을 재생하지 않습니다.

## 곡·악보 변경

`main.js` 상단의 `songs`에서 `title`, `key`, `bpm`, `sheet`를 수정하세요. 영상 목록과 연습곡 목록은 별도입니다. 기본 곡·키·BPM은 예시이며 영상과 연결되지 않습니다.

`sheet: null`이면 안내 문구를 표시합니다. 직접 제작했거나 사용 권한을 가진 악보 이미지를 폴더에 넣고 `sheet: './scores/song.png'`로 지정하세요. 외부 이미지·모델이나 악보는 기본 제공하지 않습니다. 모든 공간·악기·아바타는 기본 도형으로 생성합니다.

## Cloudflare Pages 정적 배포

빌드 명령 없이 다음 파일을 같은 루트에 배포하면 됩니다.

```text
index.html
main.js
style.css
playlist.json
```

Pages의 정적 사이트 업로드 또는 Git 연동을 사용하고, 프레임워크는 없음, 빌드 출력 경로는 이 파일들이 위치한 디렉터리로 지정하세요. 별도 환경 변수·Functions·Worker가 필요 없습니다. 로그 파일·상위 계획 문서·숨김 폴더는 업로드 대상에서 제외하세요. 배포 후 HTTPS 주소에서 데스크톱·모바일의 WebGL, 영상 임베드, 소리를 확인하세요. 이 작업에서는 실제 Cloudflare 계정에 배포하지 않았습니다.

## 범위와 참고

localStorage에는 `praise-room-profile` 키 하나로 닉네임·파트만 저장합니다. 저장이 차단된 브라우저에서도 입장할 수 있습니다. 채팅·로그인·음성통화·멀티플레이어·출석 저장은 포함하지 않습니다. YouTube를 불러오면 YouTube의 외부 서비스 정책이 적용됩니다.

레퍼런스: <https://sansatemple.com/?room=maru&instance=0&region=apac>. 구현 시 직접 접속은 도구에서 실패하여, 상위 `online-praise-room-plan.md`의 직접 관찰 기록과 사용자가 지정한 상호작용을 참고했습니다. 실제 교회 평면도를 복제한 모델은 아닙니다. 천장과 뒤 벽을 열어 3인칭 시야를 확보했습니다.

## 검증 기록

- `node --check main.js`, `python3 -m json.tool playlist.json` 통과.
- Headless Chromium에서 3D 렌더링, 입장·랜덤 이름, 키보드·바닥 클릭 이동, 카메라 드래그·휠 줌, 악보대 클릭, 앉기·일어서기, 곡 목록·악보 안내, 메트로놈 토글, 이모트 3초 표시 및 프로필 저장을 점검했습니다.
- 터치 환경의 조이스틱과 세로 390×844 / 가로 844×390 배치를 점검했습니다.
- 테스트 VM의 렌더링 부하를 줄이기 위해 자동 검증에서는 프레임을 수동으로 진행했고 Three.js CDN 요청은 같은 버전의 npm 배포 파일로 대체했습니다. 실제 앱은 연속 렌더링과 CDN import를 사용합니다.
- YouTube API 제어와 반복 확대·복귀는 테스트 대역으로 검증했습니다. 실제 영상의 임베드 가능 여부·음성 출력·기기별 실시간 성능과 Cloudflare 배포는 별도 확인이 필요합니다.
